
# Confirmation

This task is to ensure that you are able to install the required dependencies for running the test cases. The instructions below relate to the file `confirm.js` and the function `confirmation`.

1. Make sure you have changed your terminal current working directory to where this document is.

2. Make sure you run `npm install` to ensure that jest is installed, you will need to do this for all tasks included.

3. Change the string `'Not Working'` to `'Working'`.

4. Run the command `npm test`, to ensure that it passes the test cases.


If you happen to run into any issues, please notify the teacher for assistance. If you have passed the test cases for this task, please continue onto the next task.
